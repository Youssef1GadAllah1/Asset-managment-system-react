### Common Issues
1. Dependencies not installing?
   - Run: `npm cache clean --force`
   - Then: `npm install`

2. Port 3000 already in use?
   - Edit `vite.config.js`
   - Change port number

3. Data not persisting?
   - Check if localStorage enabled
   - Clear browser cache
   - Try incognito window
